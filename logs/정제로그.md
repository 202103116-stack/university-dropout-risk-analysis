# 정제 로그 (수집·정제 20점 — 몇 건이 아니라 '왜'가 점수)

> 이 파일은 노트북 ③ 정제 셀의 출력과 같은 값을 정리한 기록이다. 건수는 **코드가 계산한 값만** 쓴다.
> 보고서·발표에 쓰기 전에 노트북을 '다시 시작 및 모두 실행'해 같은 숫자가 나오는지 직접 확인한다.
> 기대값 칸의 숫자는 계획서 기준값 — 노트북 재실행으로 확정 필요.
>
> **원칙**
> - 분석 범위(예측에 쓰는 표본 + 비율의 분모·분자)에 영향이 있는지 먼저 센 뒤 처리하고, 손대지 않은 것도 이유를 남긴다.
> - 행은 지우지 않고 **표시(flag) 후 분석 표본에서 제외**하며 제외 건수·근거를 공개한다.
> - 평균 대체 같은 보정은 y 자체(중도탈락학생비율)에는 하지 않는다.
> - 결과를 바꾸는 처리는 선택지와 장단점을 팀에 보여주고 결정을 받은 뒤 한다.

## 3. 전체에 적용한 처리 vs 분석 표본 안에서만 적용한 처리
**전체 표에 적용 (표본과 무관)**
| 처리 | 왜 전체에 적용했나 |
|---|---|
| 컬럼명·문자열 공백 제거 | 형식 문제라 표본과 상관없이 해야 코드가 깨지지 않음 |
| 숫자 타입 확인·변환 | 컬럼 단위 변환 |
| 이슈 표시(flag) 컬럼 추가 | 값을 바꾸지 않는 표시라 전체에 붙여 추적표를 같은 기준으로 셈 |

**분석 표본 안에서만 적용**
| 처리 | 왜 표본 안만인가 |
|---|---|
| 재적=0·비율 결측·폐교·신설 행 제외 | 값을 지우거나 고치지 않고 표본 정의에서만 뺌. 원본 행은 그대로 남아 건수를 공개 |
| 직전연도 재적 ≥ 30 (민감도 10·50) | 소규모 학과 비율 변동 통제. 기준은 분석 설계에서 사전 고정 |
| (노트북 실행 후 기입) | |

> 기준: "값 자체를 바꾸는 보정"은 하지 않고, "표본에 넣을지 말지"만 정한다. y(비율)는 공시값을 그대로 쓴다.
