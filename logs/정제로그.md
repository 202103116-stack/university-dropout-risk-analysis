## 표 3. 전체에 적용한 처리 vs 분석 표본 안에서만 적용한 처리
**전체 표에 적용 (범위, 표본과 무관)**
| 처리 | 전체에 적용한 이유 |
|---|---|
| 컬럼명, 문자열 공백 제거 | 형식 문제라 표본과 상관없이 해야 코드가 깨지지 않음 |
| 숫자 타입 확인, 변환 | 컬럼 단위 변환 |
| 이슈 표시(flag) 컬럼과 `in_scope` 표시 추가 | 값을 바꾸지 않는 표시라 전체에 붙여, 추적표를 같은 기준으로 셈 |

**분석 표본 안에서만 적용**
| 처리 | 표본 안에서만 적용한 이유 |
|---|---|
| 범위 밖 행(사이버, 산업, 교육대, 야간, 계약학과, 폐교 등) 제외 | 탈락 메커니즘이 다름. 행은 남기고 민감도 ②에서 다시 사용 |
| 재적=0, 비율 결측, 신설 행 제외 | 값을 지우거나 고치지 않고 표본 정의에서만 뺌. 원본 행은 남아 있어 건수를 공개 |
| 직전연도 재적 ≥ 30 (민감도 10, 50) | 소규모 학과의 비율 변동을 통제. 기준은 분석 설계에서 사전 고정 |

> 기준: "값 자체를 바꾸는 보정"은 하지 않는다. "표본에 넣을지 말지"만 정한다. y(비율)는 공시값을 그대로 쓴다.

## 표 8. 손대지 않기로 한 것
- **비율 100% 초과 행**: 값을 고치지 않고 표시만 한다. 최소 재적 기준으로 통제하고, 민감도로 영향을 확인한다.
- **사유 컬럼**: 사유합 = 계 정합성이 확인되면 보정하지 않는다.
- **y(중도탈락학생비율)**: 평균 대체 등 어떤 보정도 하지 않는다.
- **표준분류 대, 중, 소계열**
  - 학과를 재분류하지 않고, 수작업 매핑표도 만들지 않는다.
  - 애매한 학과는 데이터 값을 그대로 쓴다(예: 글로벌스포츠산업학부 = 경영, 경제 / 경영학).
  - N.C.E.는 하나의 '분류 불가' 범주로 둔다.
  - 이유: 팀이 분류를 바꾸면 결과를 보고 그룹을 고르는 위험이 생긴다. 분류가 갈리는 문제는 한계로 공개한다.
- **범위 밖 행**: 지우지 않고 `in_scope=False`로 남긴다. 민감도 ②에서 다시 쓴다.
- **한국외대 학과코드 변동**: 학과명으로 억지로 이어 붙이지 않는다. 대신 B는 군 단위 풀링으로 비교한다.
- **학부, 전공 이중 계상 가능성(한국외대)**: 값은 바꾸지 않는다. 재적 합계와 학교 공시 총재적을 대조해 확인 결과만 기록한다. `[확인 필요]`
- **재적 0인데 비율 0%로 기록된 1,697행**: 0%를 결측으로 바꾸지 않는다. 대신 `rate_valid`(재적>0)로 y에서 빼고, 원본 값은 그대로 둔다.
- **신설 학교의 학과**: v2 범위 조건은 폐교만 제외한다. 전년도 행이 있는 신설 학교 학과(분석 표본 13쌍)는 그대로 남긴다.
- **개편 전 잔류, 신설 초기로 추정되는 작은 단위**(한국외대 19개, 연평균 재적 30명 미만): 행과 값은 그대로 두고, 부록 R1의 비율 순위에서만 '비율 해석 불가'로 표시해 뺀다(노트북 sE-02, 원판정 sE-01은 그대로). 근거: 재적 감소, 학과코드 소멸, 탈락 사유 대부분 미복학. 개편 이력은 `[확인 필요]`.
- **기준연도 ≠ 공시연도 − 1인 행**(연도별 101~172행): 공시연도를 시간 축으로 쓴다. 기준연도는 바꾸지 않는다(s2-03).
