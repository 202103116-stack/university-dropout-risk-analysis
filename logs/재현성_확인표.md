# 재현성 확인표 (노트북을 처음부터 재실행할 수 없으면 −5점, 보고서 부록 A)

> 단계 이름은 안내문 5단계(① 문제 정의 / ② 수집 / ③ 정제 / ④ 분석 / ⑤ 발표)를 따른다. 기대값은 계획서 기준값.

> 보고서 부록 A에 그대로 붙이는 양식. 세 사람이 각자 Colab에서 "런타임 → 다시 시작 및 모두 실행"을 돌린 뒤 채운다.
> **숫자가 다르게 나오면 그 자체가 '발견'이다.** 원인을 찾아 고친 과정을 아래 "발견" 절에 기록한다.

## 본표 — 제출 노트북(공유 Colab) 재실행 결과
각자 자기 계정에서 제출 노트북(링크: `[팀 입력]`)을 열고 원자료 CSV만 올린 뒤 "런타임 → 다시 시작 및 모두 실행"으로 처음부터 실행한다.

| 단계 | 확인 항목 | 박유진 | 신효주 | 정승엽 |
|---|---|---|---|---|
| 전체 | 에러 없이 완주 (O/X) | | | |
| ② 수집 | 원본 행 × 열 (기대 56,340 × 32) | | | |
| ③ 정제 | 범위 안 행 수 (일반 대학 주간, 기대 50,081) | | | |
| ③ 정제 | 정제 후 분석 표본 행 수 (학습 / 테스트) | | | |
| ④ 분석 | 가설 A: 사립 오즈비 / 비수도권 오즈비 (95% CI) | | | |
| ④ 분석 | 가설 B: 대상군 − 교내 다른 학과 차이 (95% 구간) | | | |
| ④ 분석 | 예측 절: 같은 k 정밀도 (구조 모델 / +전년도 탈락률 모델) | | | |
| ④ 분석 | 예측 절: AUC | | | |
| ④ 분석 | 기준선 ② (전년도 고위험 지속) 정밀도 | | | |
| 전체 | 실행 일시 (KST) | | | |
| 전체 | 노트북 링크 | [팀 입력] | [팀 입력] | [팀 입력] |

## 추가 검증 — 각자 다른 환경·코드로 다시 실행한 결과
제출 노트북과 별개로 다른 환경(로컬 Jupyter 등)·코드로도 같은 숫자가 나오는지 확인한 기록.

| 단계 | 확인 항목 | 팀원 1 (정승엽) | 팀원 2 (박유진) | 팀원 3 (신효주) |
|---|---|---|---|---|
| 전체 | 에러 없이 완주 (O/X) | | | |
| ③ 정제 | 범위 안 행 수 / 분석 표본 행 수 (학습 / 테스트) | | | |
| ④ 분석 | 가설 A·B 판정 수치 | | | |
| ④ 분석 | 예측 절 지표 (같은 k 정밀도, AUC) / 기준선 값 | | | |
| 전체 | 실행 일시 (KST) | | | |
| 전체 | 실행 환경 / 노트북 링크 | | | |

> 로컬 환경 기록 예: Python 3.13.14, pandas 3.0.6, scikit-learn 1.9.1, statsmodels 0.15.0 (`requirements.txt` 고정 버전). `nbconvert --execute`로 새 커널에서 처음부터 실행.
