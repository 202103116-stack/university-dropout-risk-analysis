> 보고서 부록 A에 그대로 붙이는 양식. 세 사람이 각자 Colab에서 "런타임 → 다시 시작 및 모두 실행"을 돌린 뒤 채운다.
> **숫자가 다르게 나오면 그 자체가 '발견'이다.** 원인을 찾아 고친 과정을 아래 "발견" 절에 기록한다.

## 본표 — 제출 노트북(공유 Colab) 재실행 결과
각자 자기 계정에서 제출 노트북(링크: `[팀 입력]`)을 열고 원자료 CSV만 올린 뒤 "런타임 → 다시 시작 및 모두 실행"으로 처음부터 실행한다.

| 확인 항목 | 박유진 | 신효주 | 정승엽 |
|---|---|---|---|
| 에러 없이 완주 (O/X) | | | |
| 정제 후 최종 행 수 | | | |
| 분석 표본 행 수 (학습 / 테스트) | | | |
| 모델 지표 1: 같은 k 적중률(정밀도) | | | |
| 모델 지표 2: AUC | | | |
| 기준선 ② 적중률(정밀도) | | | |
| 실행 일시 (KST) | | | |
| 노트북 링크 | [팀 입력] | [팀 입력] | [팀 입력] |

> 로컬 환경 기록 예: Python 3.13.14, pandas 3.0.6, scikit-learn 1.9.1, statsmodels 0.15.0 (`requirements.txt` 고정 버전). `nbconvert --execute`로 새 커널에서 처음부터 실행.
