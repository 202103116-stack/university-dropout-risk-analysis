# 프롬프트 모음 (9주차 프롬프트 ①~⑥ + 이 프로젝트용 채움 예)

> 9주차 강의자료의 프롬프트 ①~⑥ **원문은 이 폴더에 없다** → 원문 칸은 `[팀 입력]`. 강의자료에서 그대로 옮겨 붙인다.
> 아래 번호와 단계 연결은 세팅 프롬프트에서 확인된 것(④ = 기준선·누수·임계값·오차 비용, ⑤ = 숫자 옆 셀 번호)만 확정이고, 나머지는 추정 `[확인 필요]`.
> 모든 프롬프트는 4요소(대상·작업·기준·보고)로 쓰고, 결과는 위임·해독·검증(DDV) 후 `logs/AI활용기록.md`에 남긴다.

## 4요소 틀
```
[대상] 무엇(파일·컬럼·범위)을 대상으로
[작업] 무엇을 하라
[기준] 지켜야 할 조건 (원본 보존, assert, 누수 금지 등)
[보고] 무엇을 어떤 형식으로 보고하라
```

---

## ① 문제 정의 `[확인 필요: 번호-단계 연결]`
- 원문: `[팀 입력]`
- 이 프로젝트용 채움 예
```
[대상] 00_문제정의_가설.md의 의사결정 문장과 H1~H4
[작업] 각 가설이 데이터의 어떤 컬럼으로 판정 가능한지 대응표를 만든다
[기준] 가설·판정 규칙은 hypotheses-locked 이후 바꾸지 않는다. 집단별 탈락률을 계산하지 않는다
[보고] 가설 | 쓰는 컬럼 | 판정 지표 | 판정 규칙 표
```

## ② 수집·데이터 이해 `[확인 필요]`
- 원문: `[팀 입력]`
- 이 프로젝트용 채움 예
```
[대상] data/raw/의 중도탈락 CSV (utf-8-sig)
[작업] 행·열 수, 공시연도별 행 수, 컬럼별 dtype·고유값 수·예시값을 출력한다
[기준] 원본은 수정하지 않는다. 56,340×32, 연도별 14,350/13,628/13,928/14,434와 다르면 assert로 멈춘다
[보고] 수집 기록표와 data_description.md 2절에 붙일 표
```

## ③ 정제 `[확인 필요]`
- 원문: `[팀 입력]`
- 이 프로젝트용 채움 예
```
[대상] 원본 df 전체와 분석 표본(직전연도 재적≥30, 비율 유효, 폐교·신설 제외)
[작업] 정제로그 0~8단계 순서로 이슈를 표시(flag)하고 단계별 추적표를 만든다
[기준] 행을 지우지 않고 표시 후 표본에서 제외. y(비율)는 보정하지 않음. 건수는 코드가 계산한 값만 쓰고 기대값과 assert로 대조. 0행 필터는 멈춤
[보고] 처리·건수·근거·영향 표, 원본 → 중복 제거 후 → 분석 표본 추적표
```

## ④ 분석·예측 (기준선·누수·임계값·오차 비용)
- 원문: `[팀 입력]`
- 이 프로젝트용 채움 예
```
[대상] 분석 표본의 (학과 × 공시연도) 쌍, 학습 t=2024·2025 / 테스트 t=2026
[작업] 로지스틱 회귀를 학습하고 기준선 ①전원 고위험 아님 ②전년도 고위험 지속과 비교한다
[기준] 무작위 분할 금지, random_state=42. 당해 연도의 계·사유·비율 사용 금지(누수). 75백분위 컷은 학습 데이터로만. 기준선 ②와 같은 k에서 정밀도 비교. 임계값 근거와 오차 비용(놓친 학과 vs 불필요한 지원)을 명시
[보고] 정확도·정밀도·재현율·AUC·혼동행렬을 기준선과 한 표로, 같은 k 적중률 차이(%p), 오즈비와 95% 신뢰구간
```

## ⑤ 검증·보고 (숫자 옆 셀 번호)
- 원문: `[팀 입력]`
- 이 프로젝트용 채움 예
```
[대상] 보고서·발표에 들어갈 모든 수치
[작업] 각 수치가 어느 셀 출력에서 나왔는지 대조표를 만든다
[기준] 셀 출력이 없는 숫자는 쓰지 않는다. 재실행 후 값이 다르면 발견으로 기록
[보고] 수치 | 셀 번호 | 파일 | 재실행 일치 여부
```

## ⑥ 결론·한계 `[확인 필요]`
- 원문: `[팀 입력]`
- 이 프로젝트용 채움 예
```
[대상] H1~H4 판정 결과와 민감도 표
[작업] 가설별로 맞았다/틀렸다를 쓰고 권고를 판정 규칙에 연결한다
[기준] 반대 결과도 그대로 수용. 한계 3종(테스트 1년, 집계·상관, 생존 편향·공시 정의 변화) 필수. 절대=인원, 비중=비율 구분
[보고] 가설 | 판정 | 근거 수치(셀) | 권고 | 한계 표
```
