## ① 정제 로그
**언제 쓰나:** 정제 단계에서 코드와 로그를 AI에게 맡길 때

```
[대상] data/raw/의 중도탈락 CSV 전체(56,340행×32열). 범위는 일반 대학 주간 학과
       (학교종류=='대학교' AND 주야간구분=='주간' AND 학과특성=='일반과정' AND 학교상태!='폐교').
       분석에 쓸 열: 공시연도, 학교코드, 학교명, 학교종류, 설립구분, 설립유형, 소재지유형, 지역, 학교상태,
       학과코드, 학과명, 표준분류 대·중·소계열, 주야간구분, 학과특성, 재적학생, 계, 사유 8열, 중도탈락학생비율.
[작업] ① 완전 중복·키(공시연도·학교코드·학과코드) 중복을 가장 먼저 확인(0이면 '처리 없음'으로 기록)
       ② 재적=0, 계>재적, 비율 불일치는 지우지 말고 표시만 ③ 범위 필터 적용.
[기준] 행 삭제 금지, 비율(y)에 결측 보정 금지, 내가 정하지 않은 처리는 하지 말고 먼저 물어볼 것.
[보고] 단계마다 '처리·건수·근거·처리 후 행 수'를 표로, 기대 행 수와 일치하는지 assert 코드를 같이.
```

## ③ 로지스틱 회귀 위임
**언제 쓰나:** 모델 코드를 AI에게 맡길 때

```
[대상] 정제·범위 확정이 끝난 분석 표본(직전연도 정보 → 당해 y). y=고위험(1). 설명 변수는 가설 문서의 목록.
[작업] 시간 분리(학습 t=2024·2025, 테스트 t=2026, 무작위 분할 금지), 75백분위 컷은 학습 데이터로만 계산,
       random_state=42로 로지스틱 회귀 학습.
[기준] 테스트로만 평가, 임계값은 0.5와 지원 가능 학과 수 k 기준 두 가지.
[보고] ① 기준선 2개(전원 '고위험 아님', 전년도 고위험 지속)의 성능 ② 임계값별 정확도·정밀도·재현율·혼동행렬
       ③ AUC ④ 변수별 오즈비와 95% 신뢰구간을 한 표로.
```

## ④ 해독·검증
**언제 쓰나:** 모델 결과를 받은 직후, AI에게 결과를 의심하게 시킬 때

```
방금 만든 코드를 줄마다 한국어로 설명하고 결과에 영향을 준 가정 3개를 적어줘.
기준선 성능을 같은 표에 넣어줘.
설명 변수 중 예측 시점에 알 수 없는 값이 있는지(누수) 변수마다 점검해줘.
같은 random_state로 다시 돌려 숫자가 같은지 확인하고 다른 시드 3개의 범위도 보여줘.
이 결과로 말할 수 없는 것 2가지를 적어줘.
```

## ⑤ 분석 안전장치
**언제 쓰나:** CLAUDE.md가 없는 일반 Claude 채팅에서 분석을 시킬 때만

```
모든 숫자 옆에 계산한 코드 셀 번호를 붙이고 코드로 계산하지 않은 숫자는 쓰지 마.
데이터에 없는 정보는 '데이터에 없음'이라고 쓰고 외부 사실은 출처 URL을 주거나 [확인 필요]로 표시해.
결측·이상값·중복처럼 결과를 바꾸는 판단은 하기 전에 선택지와 장단점을 먼저 보여주고 내 결정을 기다려.
끝나면 '내가 지시한 것 / 네가 제안한 것 / 내가 채택·수정·기각한 것'을 표로 정리해줘.
```
